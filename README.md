# Nishan Portfolio

Welcome to my personal portfolio, built using **Django** and **Tailwind CSS**. This portfolio showcases my skills, projects, and experience as a web developer. It includes sections for my background, skills, work experience, and featured projects.

## Features
- A clean, modern design created using **Tailwind CSS**.
- Dynamic sections to highlight various projects, skills, and personal information.
- Real-time updates via the Django admin interface.
- Mobile responsive design for easy navigation on any device.

## Tech Stack
- **Frontend**: HTML, CSS (Tailwind CSS)
- **Backend**: Django (Python)
- **Database**: SQLite (or another choice based on configuration)
- **JavaScript**: For enhanced interactivity and smooth user experience

## Usage
- Explore various sections of the portfolio, including About Me, Projects, and Contact.
- View detailed information about each project I’ve worked on.
- Get in touch using the contact section, where you can reach out for collaboration or inquiries.
